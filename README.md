# 🍽️ Zomato Restaurant Data — Exploratory Data Analysis

## 📌 Objective
To explore and analyze the Zomato Bangalore restaurant dataset to uncover trends 
in ratings, pricing, location, and online ordering behavior.

## 📂 Dataset
- Source: Kaggle — Zomato Bangalore Restaurants Dataset
- Size: 50,000+ rows, 17 columns

## 🛠️ Tools & Libraries
- Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## 📊 Key Insights
1. Restaurants offering online ordering have higher median ratings than those that don't
2. BTM Layout and Koramangala have the highest restaurant density in Bangalore
3. ~60% of restaurants fall in the ₹200–₹600 price range for two people
4. Most ratings cluster between 3.5 and 4.2 — truly exceptional restaurants are rare
5. Cost and rating show only a weak positive correlation — affordable places compete well
